# Model coordinates

Input coordinates for our best layouts, ready to use as a starting point in your own model.

| File | What it is |
|---|---|
| `Supah_0.9873_coordinates.docx` | Coordinates for Supah_0.9873 with how to read them and what to watch out for (Italian + English) |
| `Supah_0.9873_submission.json` | The same coordinates as a submission file the scorer reads directly |

Supah_0.9873 scores 0.9873 on the official 64 × 64 grid and 0.9891 on the 128 × 128 finals grid. Coordinates are in mm and give each die's lower-left corner; no rotation; links use the scorer's automatic router. Full reports, floorplan and heat map: [`Models/Supah_0.9873/`](../Models/Supah_0.9873/) (team repo).

Watch the wire budget: this layout uses 13,435.5 of 13,500 GB/s·mm, so check every move with `verify_submission.py`.
